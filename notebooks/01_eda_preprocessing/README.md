# Datasets and Preprocessing

The analysis is based on scRNA-seq datasets derived from the **MCF7** and **HCC** cell lines.

## Sequencing technologies

Two sequencing technologies are considered:

- **SmartSeq** — higher sensitivity, generally producing richer expression profiles
- **DropSeq** — higher throughput, often sparser but scalable to larger numbers of cells

## Note
We have omitted the output of the EDA jupyter notebooks in order to avoid possible sharing of data belonging to the HCC1806 and MCF7 datasets that are not publicly available.
